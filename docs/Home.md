## Structure Overview

### Programming Foundations
기초 프로그래밍 역량과 문제 해결 능력을 다루는 영역입니다.  
알고리즘, 자료구조, 설계 원칙을 기반으로 시스템 구현의 토대를 구성합니다.

- Python
- Algorithms
- Data Structures
- Software Design Principles

### Data Engineering
데이터를 수집, 변환, 저장, 검증하는 전 과정을 다룹니다.  
재현 가능하고 확장 가능한 데이터 파이프라인 설계를 목표로 합니다.

- Data Collection
- ETL / ELT Pipeline
- Data Storage Systems
  - SQL (Relational Databases)
  - NoSQL (Planned)
- Database Design
- Data Validation & Quality

### [AI Systems](AI-Systems)
전체 생명주기를 다룹니다.  
모델 성능뿐 아니라 운영 관점의 시스템 통합까지 포함합니다.

- Machine Learning
- Deep Learning
- Model Evaluation
- Experiment Tracking
- Model Deployment

### Infrastructure
컨테이너화, 오케스트레이션, 클라우드 환경 구성 등 시스템 실행 환경을 설계합니다.  
확장성과 안정성을 고려한 배포 아키텍처를 중심으로 정리합니다.

- Docker
- Kubernetes
- Cloud Architecture
- CI/CD

### Computer Science
